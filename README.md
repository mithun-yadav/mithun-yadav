## 🚀 Featured Projects

### 🔴 [FlowMind — AI-Powered Automation Platform](#)
> *Drag. Connect. Automate. Done.*

A no-code/low-code automation engine that lets teams build intelligent workflows visually — think Zapier, but with custom logic blocks powered by AI.

- **Tech:** Next.js, Node.js, Python, Docker, GitHub Actions, WebSockets, MongoDB
- **Highlights:** 50+ pre-built integration nodes · Real-time execution logs · Role-based access control · Self-hostable via Docker Compose
- **Why it matters:** Cuts repetitive dev ops tasks by ~70% — deployed and used in internal team environments

### 🟣 [ChainVault — Web3 Portfolio & DeFi Dashboard](#)
> *Your on-chain life, beautifully visualized.*

A Web3 dashboard that aggregates wallet assets, DeFi positions, and NFT holdings across multiple chains — with real-time price feeds and transaction history.

- **Tech:** Next.js, TypeScript, ethers.js, GraphQL (The Graph), Tailwind CSS, Firebase
- **Highlights:** Multi-wallet connect (MetaMask, WalletConnect) · EVM-compatible multi-chain · Live token price charts · Gas tracker
- **Why it matters:** Bridges the gap between complex on-chain data and clean, actionable UX
